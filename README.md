# Gene-expression-modelling-with-ML-
Machine learning pipeline for gene expression analysis, feature selection, disease classification, and biological interpretation of transcriptomic data.
Machine learning model development (Linear Regression","Random Forest","Decision Tree","Gradient Boosting","KNN Regressor").
Model evaluation using accuracy, precision, recall.
Visualization of Top 10 HUB genes and biological insights.
Reproducible analysis using Python, Pandas, NumPy, Scikit-learn, and Matplotlib.
